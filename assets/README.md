# Assets Directory

This directory contains assets and sample food images for testing the **Explainable AI-Based Food and Nutrition Analysis System**.

---

## Sample Images Included
- `sample_apple.png`: Fresh red apple image for fruit category testing.
- `sample_pizza.png`: Slice of cheese pizza for fast food testing.
- `sample_broccoli.png`: Fresh green broccoli florets for vegetable testing.

You can upload any of these images via the Streamlit interface to test computer vision recognition and nutritional explainability.
